# Conceptos de Cloud Computing

## Introducción

Cloud Computing es la entrega de servicios informáticos a través de internet, permitiendo que organizaciones y usuarios accedan a recursos tecnológicos sin necesidad de poseer o administrar infraestructura física.

En lugar de comprar servidores, equipos de red, almacenamiento o mantener centros de datos locales, las organizaciones pueden consumir estos recursos bajo demanda mediante un proveedor de servicios en la nube como Microsoft Azure.

La computación en la nube proporciona flexibilidad, escalabilidad, optimización de costos y disponibilidad global, reduciendo al mismo tiempo la complejidad operativa.

---

## Limitaciones de la Computación Tradicional

La infraestructura tradicional (On-Premises) presenta diversos desafíos operativos que afectan directamente la eficiencia y la capacidad de crecimiento.

Algunas limitaciones comunes son:

* Alta inversión inicial en hardware
* Mantenimiento constante de infraestructura
* Costos de energía y refrigeración
* Dificultad para escalar recursos rápidamente
* Tiempos prolongados para desplegar nueva infraestructura
* Administración física de centros de datos

A medida que una organización crece, administrar infraestructura física se vuelve más costoso y complejo.

Cloud Computing surge como una solución a estas limitaciones.

---

## Características Fundamentales del Cloud Computing

Las plataformas en la nube ofrecen características que las diferencian significativamente de la infraestructura tradicional.

### Autoservicio Bajo Demanda

Los usuarios pueden aprovisionar recursos cuando lo necesiten sin interactuar directamente con el proveedor del servicio.

Recursos como máquinas virtuales, bases de datos o almacenamiento pueden desplegarse mediante portales web o herramientas de línea de comandos.

Ejemplo:

Una empresa crea un nuevo servidor desde Azure Portal sin necesidad de contactar a Microsoft.

---

### Elasticidad y Escalabilidad

La infraestructura en la nube puede adaptarse dinámicamente a la demanda.

Los recursos pueden aumentar cuando la demanda crece o disminuir cuando deja de ser necesario mantener determinada capacidad.

Esto evita comprar infraestructura innecesaria.

Ejemplo:

Una aplicación que hoy atiende 100 usuarios podría necesitar atender 1,000,000 usuarios en el futuro.

---

### Acceso Amplio a la Red

Los servicios cloud están disponibles a través de internet y pueden ser accedidos desde múltiples plataformas cliente.

Entre ellas:

* Windows
* Linux
* macOS
* Dispositivos móviles
* Navegadores web

Esto permite acceso global a infraestructura y aplicaciones.

---

### Agrupación de Recursos (Multi-Tenant)

Los proveedores cloud utilizan infraestructura compartida para servir a múltiples clientes, manteniendo aislamiento lógico y seguridad entre cada entorno.

Este modelo se conoce como **Multi-Tenancy**.

Sus beneficios incluyen:

* Mejor utilización del hardware
* Reducción de costos
* Asignación eficiente de recursos

---

### Servicio Medido

El uso de recursos es monitoreado constantemente.

Los clientes pagan únicamente por lo que consumen.

Este modelo normalmente se conoce como **Pay-As-You-Go**.

Ejemplos de recursos medibles:

* Tiempo de cómputo
* Espacio de almacenamiento
* Tráfico de red
* Transacciones en bases de datos

---

## Ventajas del Cloud Computing

La computación en la nube ofrece ventajas importantes frente a la infraestructura tradicional.

### Modelo de Gasto Operativo (OpEx)

Las organizaciones ya no necesitan realizar grandes inversiones iniciales en hardware.

En lugar de comprar infraestructura, los recursos se rentan según el consumo.

Esto transforma el gasto de:

**CAPEX → Gasto de Capital**

a

**OPEX → Gasto Operativo**

---

### Mayor Velocidad y Agilidad

La nueva infraestructura puede desplegarse en cuestión de minutos, en lugar de esperar días o semanas para adquirir hardware físico.

Esto acelera significativamente las operaciones.

---

### Economías de Escala

Los grandes proveedores cloud operan infraestructura a nivel global.

Gracias a esta escala, los servicios suelen ser más económicos que mantener centros de datos privados.

---

### Menor Mantenimiento de Infraestructura

Las organizaciones dejan de administrar directamente:

* Servidores físicos
* Reemplazo de hardware
* Sistemas de refrigeración
* Infraestructura eléctrica
* Operación de centros de datos

Toda la infraestructura física es gestionada por el proveedor cloud.

---

### Despliegue Global

Las aplicaciones pueden desplegarse en múltiples regiones alrededor del mundo.

Esto permite:

* Reducir latencia
* Mejorar experiencia de usuario
* Llegar a usuarios internacionales rápidamente
* Implementar redundancia geográfica

Ejemplo:

Una empresa en México puede desplegar infraestructura cercana a usuarios en Europa o Asia.

---

## Servicios que Ofrece Cloud Computing

Las plataformas cloud proporcionan recursos tecnológicos como servicios disponibles a través de internet.

Algunos ejemplos incluyen:

* Máquinas virtuales
* Almacenamiento
* Bases de datos
* Redes virtuales
* Gestión de identidades
* Herramientas de monitoreo
* Soluciones de seguridad
* Hospedaje de aplicaciones

Microsoft Azure es un ejemplo de plataforma cloud global que proporciona estos servicios bajo demanda.

---

## Resumen

Cloud Computing reemplaza la administración tradicional de infraestructura física mediante servicios tecnológicos accesibles a través de internet.

Su valor principal se basa en:

* Flexibilidad
* Escalabilidad
* Optimización de costos
* Alta disponibilidad
* Menor complejidad operativa
* Despliegue rápido

Comprender estos conceptos es fundamental antes de estudiar la arquitectura y los servicios específicos de Azure.
